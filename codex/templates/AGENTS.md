## Minimal Codex Harness

- Use the smallest workflow that fits the task; do not invoke agents or skills just to be ceremonial.
- For risky or broad edits, map first, implement second, review third, and verify before signoff.
- Prefer `code-mapper` for read-only path tracing before changing unfamiliar code.
- Prefer `reviewer` for correctness, security, regression, and missing-test review.
- Prefer `docs-researcher` when behavior depends on current framework, API, or tool documentation.
- Keep MCP and web research evidence-bound: cite current primary sources when they affect the decision.
- Do not claim completion without naming the checks that support the claim.
